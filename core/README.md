# هسته‌ی تونل iOS — sing-box (libbox)

این پوشه فقط ماژول Go برای ساخت چارچوب `Libbox.xcframework` است. خودِ اپ
(سوئیفت) هیچ کدی از Go ندارد؛ افزونه‌ی تونل از طریق gomobile به این
چارچوب وصل می‌شود.

## چرا sing-box v1.11.8؟

- API کلاسیک libbox در این نسخه برقرار است: `Setup`، `NewService` و
  `BoxService.Start` / `Close`؛ `PlatformInterface` شامل `OpenTun` است
  که توصیف‌گر فایل رابط utun را برمی‌گرداند.
- در sing-box 1.14، `BoxService` و `NewService` حذف شده‌اند و چرخه‌ی
  حیات به `CommandServer` + gRPC منتقل شده است؛ بدون مهاجرت کامل به
  CommandServer به 1.14 ارتقا ندهید.
- در 1.13 به بعد یک اصلاح مسابقه‌ی رابط شبکه آمده که در 1.11.8 لازم نیست.

## ساخت (روی مک، در CI انجام می‌شود)

```sh
./core/scripts/build-libbox.sh
```

خروجی: `core/Libbox.xcframework` — پروژه‌ی Xcode آن را از همین مسیر
ارجاع می‌دهد (`core/Libbox.xcframework` در `project.pbxproj`).

## تطبیق API

بعد از ساخت، اسکریپت زیر نمادهایی را که کد سوئیفت افزونه استفاده می‌کند
در سربرگ تولیدشده بررسی می‌کند؛ اگر چیزی جا افتاده باشد، بیلد متوقف
می‌شود تا نام‌ها اصلاح شوند:

```sh
./core/scripts/verify-libbox-api.sh
```

## محدودیت شناخته‌شده

افزونه‌ی Packet Tunnel به مجوز سیستمی نیاز دارد که اپل فقط به حساب‌های
پولی توسعه‌دهنده می‌دهد. با اپل‌آیدی رایگان، اپ نصب و باز می‌شود و همه‌ی
بخش‌ها کار می‌کنند، اما تونل شروع نمی‌شود. جزئیات در `README-FA.md`.
